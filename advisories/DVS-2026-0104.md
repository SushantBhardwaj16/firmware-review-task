# DVS-2026-0104: upnp-relay port mapping without authentication

- Component: upnp-relay
- Affected versions: 3.0.0 up to, but not including, 3.0.6
- Severity: high
- Condition: none

## Description

The relay accepts port mapping requests from any host on the local network and does not check who sent them. Another device on the same network can open the product's ports to the internet.

## Fix

Update upnp-relay to 3.0.6 or later.
