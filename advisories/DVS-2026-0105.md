# DVS-2026-0105: kernel packet filter flaw

- Component: kernel
- Affected versions: 5.10.0 up to, but not including, 5.10.120
- Severity: high
- Condition: only kernels built with CONFIG_NET_FASTPATH_FILTER

## Description

The fast path packet filter reads past the end of a short packet. A remote sender can crash the kernel.

## Fix

Update kernel to 5.10.120 or later. Kernels built without CONFIG_NET_FASTPATH_FILTER are not affected.
