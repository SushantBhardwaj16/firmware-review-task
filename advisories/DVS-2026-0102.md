# DVS-2026-0102: zpack inflate overflow

- Component: zpack
- Affected versions: all versions below 1.2.12
- Severity: high
- Condition: none

## Description

The inflate routine can write outside its window when it reads a damaged compressed stream. A program that unpacks data from an untrusted source can crash or run the sender's code.

## Fix

Update zpack to 1.2.12 or later.
