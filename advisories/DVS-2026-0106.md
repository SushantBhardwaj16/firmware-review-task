# DVS-2026-0106: bootwarden boot check bypass

- Component: bootwarden
- Affected versions: 0.9.0 up to, but not including, 0.9.4
- Severity: medium
- Condition: none

## Description

The boot loader can skip the check of the next stage when the image header is malformed. Someone who can write to the flash can start an image that was not signed by the maker.

## Fix

Update bootwarden to 0.9.4 or later.
