# DVS-2026-0107: clipstored clip download without authentication

- Component: clipstored
- Affected versions: 1.0.0 up to, but not including, 1.3.0
- Severity: high
- Condition: none

## Description

The clip server answers download requests on its network port without checking the session. Anyone who can reach the port can download recorded clips.

## Fix

Update clipstored to 1.3.0 or later.
