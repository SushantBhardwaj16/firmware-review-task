# DVS-2026-0103: linkcfgd config import flaw

- Component: linkcfgd
- Affected versions: all versions below 2.0.0
- Severity: high
- Condition: none

## Description

The configuration import does not check the length of a record in the imported file. A user who may import a configuration can overwrite memory in the daemon, which runs as root.

## Fix

Update linkcfgd to 2.0.0 or later.
