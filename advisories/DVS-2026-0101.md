# DVS-2026-0101: fernhttpd CGI handler overflow

- Component: fernhttpd
- Affected versions: 2.0.0 up to, but not including, 2.5.0
- Severity: high
- Condition: only builds with CGI support (configure option --enable-cgi)

## Description

The CGI handler copies a request header into a fixed buffer without checking its length. A remote client can crash the server or run code with the server's rights.

## Fix

Update fernhttpd to 2.5.0 or later. Builds without CGI support are not affected.
